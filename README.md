# SkyBlock Bazaar Tracker

Small script that prints the Hypixel SkyBlock Bazaar items with the widest
buy/sell order spread right now, i.e. the items with the biggest potential
per-unit profit for a Bazaar flip.

Uses only Hypixel's public Bazaar endpoint (`/v2/skyblock/bazaar`), so no API
key is required to run it.

## Usage

```
pip install -r requirements.txt
python bazaar_tracker.py
```
